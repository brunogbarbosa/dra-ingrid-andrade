# Dra. Ingrid Andrade

Site editorial de harmonização facial, personalizado a partir do template premium-vendas. Projeto único em Next.js, preparado para Vercel.

## Desenvolvimento

Requer Node.js 20.9 ou superior.

```sh
npm ci
npm run dev
npm run build
npm run start
```

## Vercel

Importe este repositório na Vercel. Framework: Next.js. Diretório raiz: padrão. O build usa `npm run build`; a saída é gerenciada pela integração Next.js.

O domínio de produção configurado pela Vercel é usado nos metadados. Para um domínio próprio, preencha `site.seo.url` em `data/site.ts`.
